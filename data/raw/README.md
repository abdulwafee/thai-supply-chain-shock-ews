# data/raw

Byte-identical copies of what was retrieved from each source — no parsing, no correction, no
reformatting. Excluded from Git (see `.gitignore`); this folder is regenerated by re-running
ingestion, not restored from version control.

Convention: `data/raw/<source_id>/<retrieved_at_date>/<original_filename_or_response>`, where
`source_id` matches an entry in `configs/data.yaml`.

Every retrieval should also append one line to `data/raw/_manifests/<source_id>_manifest.jsonl`
recording `retrieved_at`, `source_url`, and a checksum of the retrieved file — this is what lets
`interim/` trace every parsed value back to the exact file it came from.

No data has been placed here yet. This folder is currently empty by design (see project status in
`docs/architecture/data_architecture.md`).
