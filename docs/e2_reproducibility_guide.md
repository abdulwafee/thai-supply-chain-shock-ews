# Reproducibility guide — superseded

**This guide has been superseded by [`e2r1_reproducibility_guide.md`](e2r1_reproducibility_guide.md).**

Task E2 wrote a reproducibility guide before the owner had made three decisions:
the code licence, the release scope and the supported Python floor. Its
installation instructions have since become wrong in ways that would waste a
reader's time — it described an unverified interpreter floor and did not state
that a source checkout is the supported install mode.

Instructions that have become wrong are a hazard rather than a record, so this
file points at the current guide instead of preserving stale commands. Task E2's
*findings* — its blocked status, its missing-licence finding, its original
interpreter expectation and the correction that followed — are preserved
unedited and pinned by checksum in `docs/e2_release_readiness.json`,
`docs/e2_release_readiness.md`, `docs/e2_release_candidate_manifest.json` and
`docs/e2_release_checklist.md`.
