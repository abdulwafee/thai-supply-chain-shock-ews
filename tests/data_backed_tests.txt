# Data-backed test registry (Task E2).
#
# Each entry needs a local non-redistributable input: an official third-party
# download whose redistribution terms are unresolved, or a git-ignored
# generated table. tests/conftest.py skips these ONLY when those inputs are
# absent from the checkout, so a full working tree runs every one of them and
# skips nothing.
#
# Derived by running the suite in a release tree with this registry removed,
# then re-running each failure on its own and requiring that it fails for a
# reason naming a missing input. An entry that passed, or that failed for any
# other reason, is refused: a registry that can absorb an unrelated failure is
# a way to make a suite look green.
